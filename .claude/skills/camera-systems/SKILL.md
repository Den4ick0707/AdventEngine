# Камери

## Математика
- Матриці: `glm::lookAt` для view; `glm::perspective` для проєкції (GLM налаштований на глибину [0, 1]).
- Вісь Y у Vulkan спрямована вниз; спосіб інвертування — відкрите питання (ADR). До рішення не змішуй способи.
- Орієнтація — кути yaw і pitch, з яких будується напрямок. Pitch обмежений (близько ±89° для першої особи,
  від -80° до 45° для орбіти), інакше камера перевертається.

## Плавність без залежності від FPS
```cpp
const float t = 1.0F - std::exp(-rate * dt);   // rate близько 5–12
position = glm::mix(position, target, t);
```
`mix(position, target, 0.1F)` на кожному кадрі дає різну плавність на різних FPS.

## Порядок оновлення
- Камера оновлюється в `on_update` після руху цілі; при симуляції у фіксованому кроці — слідує
  за інтерпольованою позицією цілі (`alpha`), інакше смикається.
- Ввід миші — накопичена зміна за кадр, помножена на чутливість, без множення на `dt`.

## Типи камер
| Камера | Суть |
|--------|------|
| Вільна (налагодження, редактор) | WASD у локальних осях камери, миша — yaw і pitch, швидкість змінюється колесом |
| Від першої особи | лише огляд; позиція береться з персонажа |
| Від третьої особи (орбіта) | yaw і pitch навколо точки над ціллю; промінь від цілі до камери скорочує відстань, якщо щось заважає |
| Слідування з мертвою зоною | камера рухається, лише коли ціль виходить за межі зони; зсув уперед за напрямком руху |

## Типові помилки
- Стрибок камери при телепортації цілі: скинути згладжування.
- Тремтіння (shake) додається як зсув після згладжування, а не змінює ціль слідування.
