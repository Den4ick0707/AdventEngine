# 0003. Code style: snake_case and namespace advent

- Статус: Accepted
- Дата: 2026-11-02

## Контекст
У попередній версії код використовував PascalCase для методів, `m_PascalCase` для полів, namespace `AdventEngine::Core` і захисні макроси з подвійним підкресленням (`__ADVENTENGINE_..._HPP__`). Такі імена зарезервовані стандартом C++. Під час переробки треба обрати один стиль і перевіряти його автоматично.

## Розглянуті варіанти
1. **Залишити PascalCase-стиль**, як в Unreal чи Hazel.
2. **snake_case для функцій і змінних, PascalCase для типів** — стиль, близький до стандартної бібліотеки.

## Рішення
Варіант 2:
- типи — `PascalCase`;
- функції, методи, змінні та значення enum — `snake_case`;
- члени класу — `m_`, константи — `k_`, глобальні змінні — `g_`;
- макроси — `ADVENT_UPPER_CASE`;
- простір імен `advent` / `advent::<module>`;
- `#pragma once` замість захисних макросів;
- публічні заголовки з префіксом шляху: `<advent/<module>/file.hpp>`.

Форматування задає `.clang-format` (взято зі старої версії, доповнено). Імена перевіряє `readability-identifier-naming` у `.clang-tidy`.

## Наслідки
- Стиль перевіряється в CI (`clang-tidy --warnings-as-errors`).
- Імена cgltf, stb і Vulkan залишаються такими, як у цих бібліотеках.
