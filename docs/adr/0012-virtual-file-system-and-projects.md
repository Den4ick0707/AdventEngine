# 0012. Virtual file system, project file and settings

- Статус: Accepted
- Дата: 2026-11-05

## Контекст
Рушій шукає файли відносно поточної теки, тож результат залежить від того, звідки запущено програму.
Редактору потрібні проєкти, які можна переносити між теками й комп'ютерами, список недавніх проєктів,
налаштування користувача і місце для логів. Готову гру треба буде пакувати в архів, а модулі від спільноти
не повинні мати доступу до чужих файлів.

## Розглянуті варіанти
1. **Реальні шляхи ОС (`std::filesystem::path`) скрізь.** Просто, але шляхи залежать від ОС і місця запуску,
   у файлах сцен з'являються абсолютні шляхи, пакування в архів змінює код.
2. **Віртуальні шляхи з точками монтування.** Код працює з `project://...`, платформа відображає їх на диск
   або архів. Потрібен власний тип шляху.

## Рішення

**Віртуальні шляхи**

| Префікс | Зміст | Де фізично |
|---------|-------|-----------|
| `engine://` | ресурси рушія: шейдери, стандартні текстури | поруч із виконуваним файлом |
| `project://` | ассети й сцени проєкту | тека, де лежить файл проєкту |
| `user://` | налаштування, кеш, логи | Linux: `~/.local/share/AdventEngine/`, Windows: `%APPDATA%\AdventEngine\` |
| інші | додаткові точки з файлу проєкту, модулі | відносні шляхи від теки проєкту |

- `fs::Path` — тип у `core`: розбір, склеювання (`/`), `mount()`, `filename()`, `stem()`, `extension()`,
  `parent()`, `with_extension()`, нормалізація `..`. Повний шлях праворуч від `/` замінює лівий, як `Path.Combine`.
- Роздільник завжди `/`; порівняння чутливе до регістру на всіх ОС; вихід вище кореня монтування — помилка.
- Монтування і доступ до диска — у `platform` (`fs::mount`, `fs::read`, `fs::write`), помилки — `Result`.
  Всередині platform використовується `std::filesystem`.

**Файл проєкту** `<Name>.advent` (JSON) у корені проєкту, комітиться в Git: назва, `Uuid`, версія рушія,
стартова сцена, список модулів, додаткові точки монтування. Лише відносні шляхи; `project://` — тека файлу.

**Налаштування користувача** `user://settings.json`: недавні проєкти, налаштування редактора, перепризначені
клавіші. Абсолютні шляхи допустимі лише тут. У Git не потрапляють.

**Порядок налаштувань**: значення рушія → файл проєкту → налаштування користувача → аргументи командного рядка.

**Логи**: у Debug — поруч із виконуваним файлом (`logs/`), у Release — `user://logs/`.

## Наслідки
- Код рушія не використовує реальні шляхи, крім `platform/src`.
- Редактор отримує екран вибору проєкту з недавніх і створення нового.
- Пакування гри в архів змінює лише реалізацію монтування `project://`.
- Формат сцен — окреме рішення (тема «Серіалізація»).
