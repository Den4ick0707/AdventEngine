# 0017. Module manifest and dependency cycles

- Статус: Accepted
- Дата: 2026-11-05

## Контекст
Модулі статичні й поширюються вихідним кодом (ADR 0006). Kernel і CMake мають знати про модуль до збирання:
залежності, сумісність із рушієм, чи потрапляє модуль у готову гру. Цикли залежностей треба виявляти
до того, як вони стануть загадковими збоями.

## Рішення

**Маніфест** — `module.json` у корені теки модуля:

```json
{
  "name": "animation",
  "version": "0.2.0",
  "display_name": "Skeletal Animation",
  "description": "Skeletons, clips, sampling, joint matrices",
  "author": "Den4ick0707",
  "license": "MIT",
  "engine_api": ">=0.3.0 <0.4.0",
  "kind": "runtime",
  "dependencies": { "assets": ">=0.2.0" },
  "optional_dependencies": { "raytracing": ">=0.1.0" },
  "services": ["IAnimationSampler"]
}
```

| Поле | Зміст |
|------|-------|
| `name`, `version` | ім'я (як у `ctx.require` і назві CMake-цілі) і версія за SemVer |
| `display_name`, `description`, `author`, `license` | для людини і майбутнього каталогу модулів |
| `engine_api` | діапазон сумісних версій API рушія; несумісність — помилка конфігурації з поясненням |
| `kind` | `runtime` — потрапляє в гру; `editor` — лише в редактор (як саме він розширює редактор, вирішується в темі «Редактор») |
| `dependencies` | обов'язкові залежності з діапазонами версій; лише на них дозволено `ctx.require` |
| `optional_dependencies` | використовуються, якщо зібрані; модуль працює і без них |
| `services` | інтерфейси, які модуль надає; два постачальники одного сервісу в проєкті — помилка конфігурації |

**Цикли:**
- CMake при конфігурації читає всі маніфести (`string(JSON)`), будує граф і зупиняється на циклі
  з переліком модулів: `animation -> scene -> animation`.
- Kernel при запуску перевіряє те саме для порядку систем у фазах (ADR 0016).
- Розривання циклу: спільне виноситься в третій модуль нижче; або залежність інвертується через сервіс
  (нижчий модуль оголошує інтерфейс, вищий реалізує); або зв'язок замінюється подіями.

## Наслідки
- Кожен модуль у `engine/` і `modules/` має `module.json`.
- CMake отримує функцію, що збирає модулі з маніфестів у порядку залежностей.
- Модулі `kind: editor` не входять у збірку гри.
