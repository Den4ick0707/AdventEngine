# 0021. Renderer: bindless, render graph, deferred, compute skinning, ray tracing

- Статус: Accepted
- Дата: 2026-11-05

## Контекст
Рендерер — модуль на Vulkan 1.3 (dynamic rendering, synchronization2). Він має малювати сцену з анімованими
персонажами, приймати проходи від інших модулів (трасування променів, редактор) і стати основою диплома
з апаратним трасуванням: гібридний рендеринг і path tracer. Рішення пов'язані між собою, тому записані разом.

## Розглянуті варіанти
| Питання | Варіанти | Обрано |
|---------|----------|--------|
| Ресурси в шейдерах | класичні набори дескрипторів на матеріал; bindless | bindless |
| Організація кадру | проходи й бар'єри вручну; простий render graph; повний (aliasing, async compute) | простий граф |
| Скінінг | у вершинному шейдері; compute-прохід у буфер | compute |
| Трасування | лише гібрид; лише path tracer; обидва | обидва |
| Мова шейдерів | GLSL; HLSL; Slang | GLSL, Slang пізніше |
| Освітлення | forward; forward+ (clustered); deferred | deferred |

## Рішення

**Bindless.**
- Глобальні масиви текстур і семплерів (`descriptor indexing`, ядро Vulkan 1.2), прив'язуються раз на кадр.
  Індекс видає рендерер, коли завантажує ассет на GPU (ADR 0019).
- Дані матеріалів, об'єктів, камери — у буферах через `buffer device address`.
- Push constants — кілька індексів на draw call.
- У Debug індекси перевіряються на CPU: validation layers ловлять помилки індексів гірше, ніж прив'язок.

**Render graph** (простий).
- Прохід оголошує, що читає і що пише; граф ставить бар'єри (`synchronization2`) і відкидає проходи,
  результат яких ніхто не читає.
- Граф будується заново щокадру.
- Модулі додають проходи через сервіс рендерера, не знаючи внутрішніх проходів.
- Повторне використання пам'яті тимчасових ресурсів і async compute — пізніше, після вимірювань;
  інтерфейс проходів не змінюється.

**Deferred.**
- Непрозорі об'єкти пишуть G-buffer: колір, нормаль, шорсткість і металевість, глибина, вектори руху.
- Освітлення — compute-прохід по G-buffer.
- Прозорі об'єкти — forward-прохід після освітлення.
- Згладжування — TAA (вектори руху з G-buffer), не MSAA.
- G-buffer — вхід для RT-ефектів гібриду, TAA і денойзерів.

**Compute-скінінг.**
- Прохід `skinning` на початку кадру пише деформовані вершини в буфер кожного екземпляра за `JointMatrices` (ADR 0020).
- Далі скінований меш малюється як статичний; той самий буфер — джерело для оновлення BLAS.

**Трасування променів** — модуль `raytracing`, залежить від `renderer`.
- Доступний, лише якщо GPU підтримує розширення; рендерер повідомляє про це запитом можливостей.
  Без них рушій працює звичайно: тіні з shadow maps, без RT-ефектів.
- Рендерер володіє буферами геометрії (з прапорцями для acceleration structures); `raytracing` — acceleration
  structures: BLAS на меш (статичний — побудова один раз, скінований — refit щокадру), TLAS щокадру
  з `WorldTransform` екземплярів. Проходи `rt.build_blas`, `rt.build_tlas`, далі проходи ефектів.
- Два режими: **гібрид** (основний; растеризація плюс RT-тіні, AO, відбиття, згодом глобальне освітлення)
  і **path tracer** (еталонний; накопичення кадрів).
- Порядок: ray query для тіней і AO -> відбиття -> ray tracing pipeline і path tracer. Пізні етапи можна
  відкинути без шкоди для решти.

**Шейдери** — GLSL 460, `glslc`. Спільний код (матеріали, освітлення, доступ до bindless-масивів) — лише
в include-файлах `shaders/common/`, не дублюється. Перехід на Slang — окремим ADR, ймовірно перед path tracer.

**Системи координат.**

| Що | Конвенція |
|----|-----------|
| Світ | праворука система, Y вгору, вперед -Z (як glTF, без конвертації при імпорті) |
| Одиниці | 1 = 1 метр |
| Вісь Y екрана | від'ємна висота viewport (ядро Vulkan 1.1) |
| Глибина | reverse-Z: ближня 1, дальня 0; `D32_SFLOAT`; `GLM_FORCE_DEPTH_ZERO_TO_ONE` |
| Матриці | column-major, `M * v`, обертання — кватерніони |

## Наслідки
- Обов'язкові можливості пристрою доповнюються: `descriptorIndexing` (runtime arrays, partially bound,
  update after bind), `bufferDeviceAddress`.
- Окремих пайплайнів для скінованих мешів немає.
- Пам'ять: буфер вершин на кожен екземпляр скінованого мешу.
- Reverse-Z: порівняння глибини `GREATER`, очищення глибини в 0.
- Скіли `shader-pipeline`, `vulkan-renderer`, `skeletal-animation` оновлюються під ці правила.
