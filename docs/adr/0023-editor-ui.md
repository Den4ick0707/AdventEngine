# 0023. Editor UI: Dear ImGui (docking), editor postponed

- Статус: Accepted
- Дата: 2026-11-05

## Контекст
Редактор — окремий застосунок (ADR 0006): ієрархія сцени, інспектор, перегляд ассетів, viewport, лог.
Йому потрібні панелі, що стикуються, і кілька вікон. Найближча мета проєкту — диплом з трасуванням
променів, до якого редактор не входить.

## Розглянуті варіанти
- **Dear ImGui, гілка docking.** Immediate mode, готові backend-и для Vulkan і GLFW, панелі, що стикуються,
  винесення панелей в окремі вікна ОС. Інспектор легко будується з рефлексії (ADR 0022). Вигляд інструментальний.
- **Qt.** Повноцінні десктопні віджети, але велика залежність, окремий цикл подій, складна інтеграція
  Vulkan-viewport, LGPL.
- **Власний UI.** Повний контроль, але місяці роботи до першого результату.

## Рішення
- Бібліотека UI редактора — Dear ImGui, гілка docking (MIT). Кілька вікон — через її multi-viewport.
- Розробка редактора відкладена до завершення трасування променів (диплом). Бібліотека додається у `vendor/`,
  коли почнеться перша задача, що її потребує.
- Решта питань теми «Редактор» (функції першої версії, як модулі `kind: editor` розширюють редактор, префаби)
  лишаються відкритими до початку роботи над ним.

## Наслідки
- Dear ImGui потрапляє лише в модулі `kind: editor` і, за потреби, у debug-оверлей sandbox; у збірку гри — ні.
- Рішення про перенесення редактора відображається в `docs/roadmap.md`.
