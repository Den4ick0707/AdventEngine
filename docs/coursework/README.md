# Курсова: анімована модель з glTF

Короткий вертикальний зріз рушія для курсової роботи: від вікна до анімованої glTF-моделі з освітленням.
Строк — 12 днів. Після здачі робота продовжується за основним [планом](../roadmap.md) і
[архітектурою](../architecture.md).

План по днях і список задач — [plan.md](plan.md).

## Мета

| Що | Як перевіряється |
|----|------------------|
| Імпорт моделі з glTF 2.0 (меш, матеріал, текстура, скелет, анімації) | `CesiumMan` і `Fox` з glTF-Sample-Assets завантажуються без помилок |
| Скелетна анімація | модель анімується, кліпи перемикаються з клавіатури |
| Приємна картинка | освітлення за матеріалами glTF, тональна компресія, згладжування, площина підлоги |
| Стабільність | зміна розміру й згортання вікна без помилок, нуль `[vulkan:validation]` у `./dev smoke` |

## Спрощення відносно архітектури

Зріз будується в наявній структурі (`renderer`, `assets`, `animation`, sandbox), але без фундаменту, на який
немає часу. Кожне спрощення записане разом з ADR, до якого код повертається після здачі.

| Ціль за ADR | У курсовій | Повернення |
|-------------|------------|------------|
| Kernel, фази, системи (0015–0017) | `Application` з `on_update` і `on_render`, як зараз | етап 4 |
| Archetype ECS, ієрархія (0018) | масив екземплярів моделей у sandbox; ієрархія вузлів glTF — усередині моделі | етап 5 |
| Реєстр ассетів, `.meta`, handles (0019) | синхронне завантаження glTF за шляхом | етап 7 |
| Render graph (0021) | проходи і бар'єри вручну | етап 6 |
| Bindless (0021) | класичні набори дескрипторів: кадр, матеріал, об'єкт | етап 6 |
| Deferred і TAA (0021) | forward-рендеринг і MSAA 4x | етап 7 |
| Compute-скінінг (0021) | скінінг у вершинному шейдері | етап 8 |
| Пам'ять через `std::pmr`, `Result` (0008, 0010) | стандартні контейнери, винятки при помилці завантаження | етап 2 |
| doctest (0024) | наявні тести без змін; нові — лише якщо лишиться час | етап 2 |

## Що не спрощується

Ці правила майже нічого не коштують, але без них код після здачі довелося б переписувати, а не переробляти.

- Межі модулів: `assets` і `animation` повертають лише CPU-дані, Vulkan є лише в `renderer`.
- Системи координат з ADR 0021: праворука, Y вгору, метри, від'ємна висота viewport, reverse-Z.
- Анімація — через позу і операції `sample` і `blend` (ADR 0020); crossfade — `blend` двох `sample`.
- Стиль коду, `./dev ci` перед кожним комітом, гілки й PR у `dev`.
