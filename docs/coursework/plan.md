# Курсова: план і задачі

Межі й спрощення — [README](README.md). Пріоритети: **обов'язково** — без цього роботу не здати;
**бажано** — «гарна картинка»; **якщо лишиться час** — ріжеться першим.

## План по днях

| День | Що | Результат |
|------|----|-----------|
| 1 | swapchain, кадри в польоті, очищення кольором, перебудова при зміні розміру | вікно з кольором без помилок validation |
| 2 | компіляція шейдерів, графічний пайплайн | трикутник |
| 3 | буфери через VMA (staging), depth reverse-Z, uniform-буфер камери | обертовий куб |
| 4 | вільна камера: миша і клавіатура | переміщення сценою |
| 5–6 | `assets`: glTF через cgltf (меші, матеріали), текстури через stb, mip-рівні | `Box` і `Duck` з текстурами |
| 7 | освітлення: спрямоване світло, metallic-roughness з glTF, тональна компресія, MSAA | модель з освітленням |
| 8–9 | `animation`: скелет, кліпи, семплінг, матриці суглобів; скінінг у вершинному шейдері | `CesiumMan` анімується |
| 10 | перемикання кліпів з crossfade, кілька моделей, підлога | `Fox`: ходьба і біг з плавним переходом |
| 11 | запас: налагодження, нуль помилок validation, зміна розміру й згортання | стабільна збірка |
| 12 | скріншоти, відео, тег релізу | здача |

Якщо графік зсувається: спершу відкидаються задачі «якщо лишиться час», потім — «бажано». Анімація важливіша
за освітлення: день 7 можна скоротити до простого дифузного світла.

## Задачі

### Обов'язково
- [ ] Swapchain: формат sRGB, FIFO, перебудова при `OUT_OF_DATE`/`SUBOPTIMAL` і зміні розміру, пауза при згортанні.
- [ ] Кадри в польоті: fence і семафори на кадр, `vkQueueSubmit2`, переходи layout через `synchronization2`.
- [ ] `advent_compile_shaders` (glslc) і шейдери в `shaders/`.
- [ ] Builder графічного пайплайну з dynamic rendering.
- [ ] Буфери й зображення через VMA, завантаження через staging.
- [ ] Depth `D32_SFLOAT`, reverse-Z; від'ємна висота viewport.
- [ ] Камера: view і projection (GLM, глибина [0, 1]), вільна камера з мишею і клавіатурою.
- [ ] `assets`: `MeshData`, `MaterialData`, `ImageData`, `SkeletonData`, `AnimationClipData` з glTF (cgltf, stb).
- [ ] Рендерер: завантаження мешів і текстур на GPU, набори дескрипторів кадру, матеріалу, об'єкта.
- [ ] `animation`: `Skeleton`, `AnimationClip`, `Pose`, `sample` (linear, step, cubic spline), матриці суглобів.
- [ ] Скінінг у вершинному шейдері, SSBO матриць суглобів на кожен кадр у польоті.
- [ ] Sandbox: завантаження моделі з командного рядка, перемикання кліпів клавішами.

### Бажано («гарна картинка»)
- [ ] Освітлення metallic-roughness з glTF: спрямоване світло й навколишнє освітлення.
- [ ] Тональна компресія (ACES) і гамма через sRGB-формат swapchain.
- [ ] MSAA 4x.
- [ ] Crossfade між кліпами (`blend` двох поз).
- [ ] Кілька моделей у сцені, площина підлоги.
- [ ] Фон-градієнт неба замість суцільного кольору.

### Якщо лишиться час
- [ ] Тінь від спрямованого світла (shadow map).
- [ ] Відображення кісток лініями для налагодження.
- [ ] Тести семплінгу анімації (межі кліпу, інтерполяція між ключами).
- [ ] Знімок екрана за клавішею.

## Тестові моделі
Khronos glTF-Sample-Assets у `assets/models/` (Git LFS): `Box`, `Duck` -> `RiggedSimple`, `CesiumMan` -> `Fox`.
