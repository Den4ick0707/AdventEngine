# Огляд попередньої версії репозиторію

Перед переробкою (листопад 2026) було проаналізовано всі гілки старого репозиторію:
- `main`;
- `dev`;
- `feature/setup-repo`;
- `feature/setup-project` (останній коміт 27.08.2026).

Цей документ фіксує знайдені проблеми та те, як їх розв'язано в новій версії.
Документ історичний і не оновлюється: деякі рішення з нього згодом змінено, напр. submodules (ADR 0001) замінено копіями у `vendor/` (ADR 0005).

## Що збережено
- `.clang-format`, `.clang-tidy`, `.cmake-format.yaml` — доповнено (див. нижче).
- Ліцензія MIT, схема гілок `main` / `dev` / `feature/*`.
- Ідея CI на Windows і Linux та публікації релізів.
- Архітектурні ідеї з `feature/setup-project`:
  - базовий клас `Application` з віртуальними хуками → `runtime::Application`;
  - інтерфейс `IModule` → `runtime::Module`;
  - абстракція вікна з `GLFW_NO_API` → `platform::Window`;
  - окремий застосунок `Sandbox` → `apps/sandbox`.

## Знайдені проблеми та рішення

| # | Проблема | Наслідок | Рішення в новій версії |
|---|----------|----------|------------------------|
| 1 | Код існував лише в незлитій `feature/setup-project`; `main` містила тільки Initial commit, `dev` — конфіги | Неясно, яка версія актуальна | Новий репозиторій: `main` і `dev` містять робочий код |
| 2 | Бібліотеки скопійовані в `external_libs/` (2 542 файли, 668 тис. рядків) | Роздута історія, ручне оновлення, невідомі версії | Git submodules, зафіксовані на тегах (ADR 0001) |

## Доповнення конфігів
- `.clang-format`:
  - `AccessModifierOffset: -4` (раніше `public:` зміщувався на 2 пробіли);
  - ініціалізатори конструктора з комою на початку рядка;
  - короткі тіла дозволені лише для гетерів усередині класу.
- `.clang-tidy`:
  - вимкнено шумні для Vulkan C API правила;
  - додано `readability-identifier-naming` під стиль проєкту (ADR 0003).
- `.gitignore` переписано компактніше; `CMakeUserPresets.json` і локальні налаштування Claude Code ігноруються.
- Додано `.gitattributes`: нормалізація кінців рядків і Git LFS для моделей і текстур.
